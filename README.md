## GitHub থেকে APK বানানোর নিয়ম

1. GitHub-এ একটি নতুন repository বানাও।
2. এই ZIP ফাইল extract করে **ভেতরের সব ফাইল ও ফোল্ডার** (`app`, `.github`, `build.gradle.kts`, `settings.gradle.kts`, `gradle.properties`…) repository-র একদম root-এ আপলোড করো।
   - `.github` ফোল্ডারটি hidden থাকতে পারে। এটা না গেলে workflow চলবে না। না গেলে GitHub-এ **Add file → Create new file** চেপে নাম দাও `.github/workflows/build.yml` এবং `build.yml.txt` ফাইলের লেখা পেস্ট করে Commit করো।
3. আপলোড (commit) হলেই **Actions** ট্যাবে "Build APK" নিজে থেকে চলবে। না চললে Actions → Build APK → **Run workflow** চাপো।
4. ৫–১০ মিনিট পর কাজ সবুজ ✅ হলে ওই run-এ ঢুকে নিচে **Artifacts → app-debug-apk** ডাউনলোড করো। ZIP খুললে `app-debug.apk` পাবে। সেটা ফোনে ইনস্টল করো।

## ভিভো (Funtouch OS) ফোনে রিমাইন্ডার ঠিকমতো পেতে

অ্যাপ প্রথমবার খুললে নোটিফিকেশনের অনুমতি চাইবে — **Allow** দাও। তারপর:

- ফোনের Settings → Apps → থামবো না → Battery → **Unrestricted / ব্যাকগ্রাউন্ডে চলতে দিন**
- সম্ভব হলে **Autostart** চালু করো
- অ্যাপের ⚙️ সেটিংসে "টেস্ট নোটিফিকেশন" চেপে দেখে নাও কাজ করছে কি না

## অ্যাপের নাম বদলাতে চাইলে

`app/src/main/res/values/strings.xml` ফাইলে `app_name` বদলে দাও।
